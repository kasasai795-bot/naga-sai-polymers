# Naga Sai Polymers ERP System

A modern ERP (Enterprise Resource Planning) system and company website developed for **Naga Sai Polymers** to manage products, customers, orders, quotations, inventory, and production tracking.

---

## 🚀 Features

### ✅ Completed
- Admin Authentication
- Product Management (CRUD)
- Product Image Upload
- Search & Category Filter
- PostgreSQL Database Integration
- Prisma ORM
- GitHub Version Control

### 🚧 Upcoming
- Dashboard Analytics
- Customer Management
- Order Management
- Inventory Management
- Quotation Generator (PDF)
- Production Tracking
- Public Website Integration
- Email Notifications
- Deployment

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/kasasai795-bot/naga-sai-polymers.git
```

### Install Dependencies

Frontend

```bash
cd client
npm install
npm run dev
```

Backend

```bash
cd server
npm install
npm run dev
```
